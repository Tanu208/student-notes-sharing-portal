Academic Project Presentation Course: Cloud Computing & Systems Architecture

Cloud Computing in Academic Knowledge Systems

An architectural study on transforming localized university file sharing into an elastic, highly available cloud repository

1. What is Cloud Computing?

According to the NIST definition, cloud computing provides ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (networks, servers, storage, applications, and services) that can be rapidly provisioned with minimal management effort.

2. How Educational Clouds Operate

Educational SaaS platforms decouple heavy computing and physical disk storage from student laptops. Files are ingested, indexed with metadata in distributed databases, and streamed through global Content Delivery Networks (CDNs) with millisecond latency.

3. Benefits of Online Notes Sharing

High Availability: 99.99% uptime with zero physical server maintenance.
Accessibility: Cross-platform access on mobile, tablet, and desktop.
Fault Tolerance: Automated multi-zone replication prevents data loss.

Current Implementation (Frontend Simulation)
  • Pure HTML5, CSS3 & Vanilla JavaScript (No backend or paid API required)
  • Client-side Session Authentication via localStorage
  • Client-side Persistent File Ingestion via IndexedDB
  • Instant In-Memory Dynamic Filtering & Instant Blob Downloads
  • Zero deployment cost; fully deployable to Netlify, Vercel, or GitHub Pages
Production Cloud Architecture Roadmap
  • Object Storage: Amazon S3 / Google Cloud Storage for multi-terabyte PDF storage
  • Serverless Backend: AWS Lambda / Google Cloud Functions triggered via REST API Gateway
  • Metadata Database: Amazon DynamoDB / MongoDB Atlas for fast indexing
  • Global CDN: Amazon CloudFront / Cloudflare for low-latency edge caching
  • Identity & SSO: Amazon Cognito / Auth0 for university single sign-on
Academic Architecture Disclaimer: This version of the Student Notes Sharing Portal is intentionally engineered as an accessible, zero-dependency frontend demonstration. Notes uploaded in this browser are securely stored in your local browser sandbox (IndexedDB and LocalStorage). They are persisted on this device across browser reloads, without claiming to transmit files to a live remote cloud server.
